# Trueqify

## Descripción del proyecto

Trueqify es una plataforma diseñada para facilitar el intercambio de objetos y productos entre personas de comunidades rurales, sin utilizar dinero.

Su objetivo es promover la reutilización de objetos, la colaboración y el aprovechamiento de los recursos disponibles en las comunidades.

Los usuarios podrán registrarse, publicar productos, consultar el catálogo y enviar solicitudes de intercambio.

## Tecnologías utilizadas

### Frontend
- React 19
- Vite 8
- JavaScript
- CSS

### Base de datos
- MySQL
- MySQL Workbench

### Control de versiones
- Git
- GitHub

## Funcionalidades principales

- Registro e inicio de sesión.
- Edición del perfil de usuario.
- Publicación de productos.
- Consulta del catálogo.
- Búsqueda y filtros de productos.
- Solicitudes de intercambio.

## Instalación y ejecución

1. Clonar el repositorio:

```bash
git clone https://github.com/dannajimenez2108/Trueqify.git
```

2. Ingresar a la carpeta:

```bash
cd Trueqify
```

3. Instalar las dependencias:

```bash
npm install
```

4. Ejecutar el proyecto:

```bash
npm run dev
```
